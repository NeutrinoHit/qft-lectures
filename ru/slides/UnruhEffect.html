Суть эффекта Унру

Вакуум в квантовой теории поля

  • Вакуум - состояние с нулевым числом частиц
  • Во всех инерциальных системах вакуум - это одно и то же состояние
  • А что если наблюдатель неинерциальный?
  • Мы придём к удивительному результату: для ускоренного наблюдателя вакуум будет выглядеть как тепловое состояние с определённой температурой.
  • Рассмотрим это шаг за шагом, начиная с простейшей модели.

К чему мы придём?

  • Равномерно ускоряемый наблюдатель видит частицы из вакуума Минковского

  • Распределение частиц по энергиями даётся спектром

    • Бозе-Эйнштейна (для бозонов),
    • Ферми-Дирака (для фермионов),

  • Температура частиц, которую видит ускоренный наблюдатель: \[ T_U=\frac{\hbar a}{2\pi k_B c}. \]

  • где \(a\) — собственное ускорение детектора, \(k_B\) — постоянная Больцмана, \(c\) — скорость света.

Что это?

  • Этот эффект называется эффектом Унру по имени Вильяма Унру (1976).
  • Он показывает, что понятие частицы в квантовой теории поля зависит от наблюдателя.
  • Годом ранее в 1975 году он был обнаружен независимо Полом Дэвисом.

Насколько велик эффект Унру?

  • Температура Унру \[ T_U \approx 4.06 \times 10^{-21} \, \text{К}\times\frac{a}{\text{m}/\text{s}^2} \]

На что это похоже?

  • Это похоже на температуру излучения Хокинга: \[ T_H=\frac{\hbar g}{2\pi k_B c}, \] где \(g\) — ускорение свободного падения на горизонте черной дыры.
  • С учётом принципа эквивалентности эффекты Унру и Хокинга родственные, но не идентичные.

Плоская волна

Рассмотрим плоскую волну

  • Рассмотрим безмассовую плоскую волну вдоль оси \(x\): \[ \phi(t,x)\sim e^{-i\omega_K t+iKx}. \]
  • Здесь \(\omega_K\) — частота, а \(K\) — волновой вектор: \[ K=\pm \omega_K. \]
  • В этом педагогическом выводе волна лежит на массовой поверхности.

Частота в мгновенно сопутствующей системе

  • Преобразование Лоренца: \[ \omega'_K(\tau) = \gamma(\tau)\left(\omega_K-Kv(\tau)\right). \]
  • Волна вдоль ускорения: \(K=+\omega_K\). \[ \omega'_K(\tau) = \gamma(\tau)\omega_K\left(1-v(\tau)\right) = \omega_K\frac{1-\tanh{a\tau}}{\sqrt{1-\tanh^2{a\tau}}} =\omega_K e^{-a\tau}. \]
  • Волна против ускорения: \(K=-\omega_K\). \[ \omega'_K(\tau) = \gamma(\tau)\omega_K\left(1+v(\tau)\right) = \omega_K\frac{1+\tanh{a\tau}}{\sqrt{1-\tanh^2{a\tau}}} =\omega_K e^{+a\tau}. \]

Частота в мгновенно сопутствующей системе

  • Волна вдоль ускорения: \(K=+\omega_K\). \[ \boxed{ \omega'_K(\tau) = \omega_K e^{-a\tau}} \]
  • Волна против ускорения: \(K=-\omega_K\). \[ \boxed{ \omega'_K(\tau) = \omega_K e^{+a\tau}} \]
  • Для малых значений \(a\tau\) - это обычный эффект Доплера: \[ \omega'_K(\tau) \approx \omega_K(1\mp a\tau). \]

Эффект Доплера для инерциального наблюдателя

  • Плоская волна: \(\phi(t,x)\sim e^{-i\omega_K t+iKx}\)
  • и инерциального наблюдателя: \[ t(\tau)=\gamma\tau, \quad x(\tau)=\gamma v \tau. \]
  • Фаза на мировой линии наблюдателя (скорость \(v\)): \[ \Phi(\tau)=K x(\tau)-\omega_K t(\tau)=-\gamma\tau(\omega_K-Kv). \]
  • Мгновенная частота: \[ \omega'(\tau)=-\frac{d\Phi}{d\tau}=\gamma(\omega_K-Kv)=\text{const}. \]

Эффект Доплера для неинерциального наблюдателя

  • Волна вдоль ускорения: \(K=+\omega_K\). \[ \boxed{ \omega'_K(\tau) = \omega_K e^{-a\tau}} \]
  • Волна против ускорения: \(K=-\omega_K\). \[ \boxed{ \omega'_K(\tau) = \omega_K e^{+a\tau}} \]
  • Частота меняется со временем \(\tau\)!
  • Наблюдается спектр частот.

Фурье-спектр детектора

  • Фурье-разложение сигнала детектора: \[ f(\tau) = \int \frac{d\Omega}{2\pi}\,F(\Omega)\,e^{-i\Omega\tau}. \]
  • Амплитуда фурье-компоненты: \[ F(\Omega) = \int_{-\infty}^{\infty} d\tau\, f(\tau)\,e^{i\Omega\tau}. \]
  • Спектральная интенсивность: \[ S(\Omega)\propto |F(\Omega)|^2. \]

Что видит ускоренный детектор?

  • Плоская волна: \(\phi(t,x)\sim e^{-i\omega_K t+iKx}\)
  • Фаза на мировой линии наблюдателя: \[ \Phi(\tau)=K x(\tau)-\omega_K t(\tau)=-\gamma\tau(\omega_K-Kv). \]
  • Мгновенная частота (\(K=-\omega_K\)): \[ -\frac{d\Phi}{d\tau} =\gamma(\omega_K-Kv)=\boxed{\omega'(\tau)=\omega_K e^{+a\tau}} \]
  • Накопленная фаза: \[ \boxed{ \varphi(\tau) = \int^\tau_{-\infty} \omega'_K(\tau')\,d\tau' = \frac{\omega_K}{a} e^{+a\tau}} \]

Что видит ускоренный детектор?

  • Итак, \[ f(\tau) = e^{i\varphi(\tau)} = e^{ i(\omega_K/a)e^{a\tau} }. \]
  • Фурье-амплитуда для частоты \(\Omega\): \[ F(\Omega) = \int_{-\infty}^{\infty} d\tau\, e^{i\Omega\tau} e^{ i(\omega_K/a)e^{a\tau} } \]
  • В результате (сейчас мы это докажем): \[ \boxed{ |F(\Omega)|^2 = \frac{2\pi}{a\Omega}\frac{1}{e^{2\pi\Omega/a}-1}. } \]

Что видит ускоренный детектор?

  • Планковский спектр: \[ \boxed{ |F(\Omega)|^2 = \frac{2\pi}{a\Omega}\frac{1}{e^{2\pi\Omega/a}-1}. } \]
  • Температура Унру: \[ T_U=\frac{a}{2\pi k_B} \equiv \frac{\hbar a}{2\pi k_B c} \quad (\hbar=1, \, c=1). \]
  • Точно такой же результат получится для (\(K=+\omega_K\))

Вывод формулы

  • Замена переменной в интеграле: \[ y=e^{a\tau}. \]
  • Тогда \[ \tau=\frac{1}{a}\ln y, \qquad d\tau=\frac{1}{a}\frac{dy}{y}. \]
  • Пределы: \[ \tau:-\infty\to+\infty \quad\Longrightarrow\quad y:0\to\infty. \]
  • Стало быть: \[ e^{i\Omega\tau} = e^{i\Omega\frac{1}{a}\ln y} = e^{\ln y^{i\Omega/a}} = y^{i\Omega/a}. \]

  • Интеграл (\(y=e^{a\tau}\), \(d\tau=\frac{1}{a}\frac{dy}{y}\), \(e^{i\Omega\tau}=y^{i\Omega/a}\)): \[ \begin{aligned} F(\Omega) &= \int_{-\infty}^{\infty} d\tau\, e^{i\Omega\tau} e^{ i(\omega_K/a)e^{a\tau} }\\ &= \frac{1}{a} \int_0^\infty dy\, y^{i\Omega/a-1} e^{i\frac{\omega_K}{a}y} \end{aligned} \]
  • Этот интеграл выражается через гамма-функцию: \[ \int_0^\infty dy\, y^{s-1}e^{-\lambda y} = \frac{\Gamma(s)}{\lambda^s}. \]

Фурье-амплитуда

  • Стало быть, \[ F(\Omega) = \frac{1}{a} \Gamma\left(i\Omega /a\right) \left(\frac{\omega_K}{a}\right)^{-i\Omega/a} e^{-\pi\Omega/(2a)}. \]
  • Квадрат модуля: \[ |F(\Omega)|^2 = \frac{1}{a^2} \left|\Gamma\left(i\Omega/a\right)\right|^2 e^{-\pi\Omega/a}. \]
  • Тождество для гамма-функции \[ |\Gamma(ix)|^2 = \frac{\pi}{x\sinh(\pi x)}. \]

Фурье-спектр сигнала

  • Используя тождество для гамма-функции, получаем \[ \boxed{ |F(\Omega)|^2 = \frac{2\pi}{\Omega a} \frac{1}{e^{2\pi\Omega/a}-1}} \]

Краткое резюме

  • Главная идея первых шагов: \[ t(\tau)=\frac{1}{a}\sinh a\tau, \qquad x(\tau)=\frac{1}{a}\cosh a\tau. \]
  • Плоская волна вдоль ускоренной траектории становится сигналом \[ f(\tau) = e^{i(\omega_K/a)e^{a\tau}} \]
  • Мощность спектра сигнала: \[ \boxed{ |F(\Omega)|^2 = \frac{2\pi}{\Omega a} \frac{1}{e^{2\pi\Omega/a}-1}} \]
  • Температура Унру: \[ T_U=\frac{a}{2\pi k_B}. \]

Почему этого недостаточно?

  • Мы рассмотрели плоскую волну с определенной частотой и на массовой поверхности.
  • В квантовом поле нужно учесть все остальные моды.

Квантовое поле и спектр шума

Поле и спектральный коррелятор

Соглашения

  • Работаем в \(1+1\) и используем \[ c=\hbar=k_B=1. \]

  • Безмассовое вещественное скалярное поле: $$ (t,x) = _{-}^{+} , [ a_p e^{-i_p t+ipx}

  • a_p^e^{+i_p t-ipx} ], _p=|p|. $$

  • Коммутационные соотношения: \[ [\hat a_p,\hat a_q^\dagger] = 2\pi\delta(p-q), \qquad [\hat a_p,\hat a_q]=0. \]

Сигнал наблюдателя

  • Наблюдатель движется по мировой линии \[ x^\mu=x^\mu(\lambda)=(t(\lambda),x(\lambda)). \]

  • Он регистрирует поле только вдоль своей траектории: \[ \phi_{\rm obs}(\lambda) = \phi(t(\lambda),x(\lambda)). \]

  • Частоты наблюдателя определяются фурье-разложением по его времени: \[ \hat g(\Omega) = \int_{-\infty}^{+\infty} d\lambda\, e^{i\Omega\lambda} \phi_{\rm obs}(\lambda). \]

  • Для инерциального наблюдателя (=t).
    Для ускоренного наблюдателя (=).

Спектральный коррелятор

  • Рассмотрим \[ C(\Omega,\Omega') = \left\langle \hat g^\dagger(\Omega) \hat g(\Omega') \right\rangle, \qquad \Omega,\Omega'>0. \]

  • Это корреляция фурье-компонент сигнала поля.

  • Если состояние стационарно относительно времени наблюдателя, то разные частоты не коррелируют: \[ C(\Omega,\Omega') = 2\pi\delta(\Omega-\Omega')S(\Omega). \]

Инерциальный наблюдатель

Фурье-компонента в инерциальной системе

  • Пусть наблюдатель покоится: \[ t=\tau, \qquad x=0. \]

  • Тогда $$ _{}() = [ a_p e^{-i_p}

  • a_p^e^{+i_p} ]. $$

  • Для (>0): \[ \hat g_{\rm I}(\Omega) = \int d\tau\,e^{i\Omega\tau}\phi_{\rm I}(\tau) = \frac{\hat a_{\Omega}+\hat a_{-\Omega}}{\sqrt{2\Omega}}. \]

  • Инерциальная положительная частота выбирает операторы уничтожения.

Инерциальный вакуум

  • Вакуум Минковского: \[ \hat a_p|0_M\rangle=0. \]

  • Поэтому \[ \langle 0_M| \hat a_p^\dagger \hat a_q |0_M\rangle=0. \]

  • Следовательно, $$ \boxed{ M| g{}^() g_{}(’) |0_M =

  1. } $$
  • Инерциальный наблюдатель не видит частиц в вакууме Минковского.

Инерциальное состояние с частицами

  • Пусть \[ \langle \hat a_p^\dagger\hat a_q\rangle = 2\pi n(\omega_p)\delta(p-q). \]

  • Тогда \[ \langle \hat g_{\rm I}^\dagger(\Omega) \hat g_{\rm I}(\Omega') \rangle = 2\pi\delta(\Omega-\Omega') \frac{n(\Omega)}{\Omega}. \]

  • Значит \[ \boxed{ S_{\rm I}(\Omega) = \frac{n(\Omega)}{\Omega}. } \]

  • Спектральная плотность напрямую измеряет число частиц в моде.

Инерциальное тепловое состояние

  • Для теплового состояния: \[ n(\Omega) = n_B(\Omega) = \frac{1}{e^{\beta\Omega}-1}, \qquad \beta=\frac{1}{T}. \]

  • Тогда \[ \boxed{ S_{\rm I}^{T}(\Omega) = \frac{1}{\Omega} \frac{1}{e^{\beta\Omega}-1}. } \]

  • Это обычный бозе-эйнштейновский спектр.

Энтропия инерциальных мод

  • Одна бозонная мода с occupation number (n): \[ \rho_n = \frac{1}{1+n} \sum_{m=0}^{\infty} \left(\frac{n}{1+n}\right)^m |m\rangle\langle m|. \]

  • Энтропия моды: \[ s(n) = -\mathrm{Tr}\,\rho_n\ln\rho_n = (1+n)\ln(1+n)-n\ln n. \]

  • Для вакуума: \[ n=0 \quad\Longrightarrow\quad s(0)=0. \]

  • Глобальный вакуум Минковского — чистое состояние: \[ \rho_M=|0_M\rangle\langle0_M|, \qquad S_M=-\mathrm{Tr}\,\rho_M\ln\rho_M=0. \]

Ускоренный наблюдатель

Мировая линия

  • Равномерно ускоренный наблюдатель: \[ t(\tau)=\frac{1}{a}\sinh a\tau, \qquad x(\tau)=\frac{1}{a}\cosh a\tau. \]

  • Здесь (a) — собственное ускорение.

  • Наблюдатель анализирует поле по своему собственному времени: \[ \hat g_{\rm R}(\Omega) = \int_{-\infty}^{+\infty} d\tau\, e^{i\Omega\tau} \phi(t(\tau),x(\tau)). \]

Ускоренная фурье-компонента

  • Подставляем разложение поля: $$ g_{}() = [ a_p I_p()

  • a_p^J_p() ]. $$

  • Здесь \[ I_p(\Omega) = \int d\tau\, e^{i\Omega\tau} e^{-i\omega_p t(\tau)+ipx(\tau)}, \]

\[ J_p(\Omega) = \int d\tau\, e^{i\Omega\tau} e^{+i\omega_p t(\tau)-ipx(\tau)}. \]

  • В отличие от инерциального случая, положительная частота по () содержит и (a_p), и (a_p^).

Основной интеграл

  • Запишем \[ p=\epsilon\omega, \qquad \epsilon=\pm1, \qquad \omega>0. \]

  • Для коэффициента при (a_p^): \[ J_\epsilon(\Omega,\omega) = \int_{-\infty}^{+\infty} d\tau\, e^{i\Omega\tau} \exp\left[ -i\epsilon\frac{\omega}{a}e^{-\epsilon a\tau} \right]. \]

  • Этот интеграл равен \[ \boxed{ J_\epsilon(\Omega,\omega) = \frac{1}{a} \Gamma\left(-i\epsilon\frac{\Omega}{a}\right) \left(\frac{\omega}{a}\right)^{i\epsilon\Omega/a} e^{-\pi\Omega/(2a)}. } \]

Вакуум Минковского для ускоренного наблюдателя

  • В вакууме Минковского \[ \langle 0_M|\hat a_p^\dagger\hat a_q|0_M\rangle=0, \] но \[ \langle 0_M|\hat a_p\hat a_q^\dagger|0_M\rangle = 2\pi\delta(p-q). \]

  • Поэтому \[ \langle 0_M| \hat g_{\rm R}^\dagger(\Omega) \hat g_{\rm R}(\Omega') |0_M\rangle \neq0. \]

  • Выживает вклад от коэффициентов (J_): \[ C_{\rm R}(\Omega,\Omega') = \sum_{\epsilon=\pm1} \int_0^\infty \frac{d\omega}{2\pi} \frac{1}{2\omega} J_\epsilon^*(\Omega,\omega) J_\epsilon(\Omega',\omega). \]

Откуда берётся ((-’))?

  • После подстановки (J_) появляется интеграл \[ \int_0^\infty \frac{d\omega}{\omega} \left(\frac{\omega}{a}\right)^{ i\epsilon(\Omega'-\Omega)/a }. \]

  • Сделаем замену \[ s=\ln\frac{\omega}{a}, \qquad \frac{d\omega}{\omega}=ds. \]

  • Тогда \[ \int_{-\infty}^{+\infty} ds\, e^{i\epsilon(\Omega'-\Omega)s/a} = 2\pi a\,\delta(\Omega'-\Omega). \]

  • Стационарность по () проявляется как диагональность по частотам.

Спектр Минковского вакуума в ускоренной системе

  • Получаем \[ \langle 0_M| \hat g_{\rm R}^\dagger(\Omega) \hat g_{\rm R}(\Omega') |0_M\rangle = 2\pi\delta(\Omega-\Omega')S_{\rm R}(\Omega). \]

  • Где \[ S_{\rm R}(\Omega) = \frac{1}{\Omega} \frac{1}{e^{2\pi\Omega/a}-1}. \]

  • То есть \[ \boxed{ n_{\rm R}^{(M)}(\Omega) = \frac{1}{e^{2\pi\Omega/a}-1}. } \]

  • Минковский вакуум выглядит как тепловое состояние для ускоренного наблюдателя.

Температура Унру

  • Сравниваем с тепловым инерциальным спектром: \[ S_{\rm I}^{T}(\Omega) = \frac{1}{\Omega} \frac{1}{e^{\beta\Omega}-1}. \]

  • У ускоренного наблюдателя: \[ S_{\rm R}(\Omega) = \frac{1}{\Omega} \frac{1}{e^{2\pi\Omega/a}-1}. \]

  • Поэтому \[ \beta_U=\frac{2\pi}{a}, \qquad T_U=\frac{a}{2\pi}. \]

  • В обычных единицах: \[ \boxed{ T_U=\frac{\hbar a}{2\pi k_B c}. } \]

Энтропия для ускоренного наблюдателя

  • Для каждой риндлеровской частоты: \[ n_U(\Omega) = \frac{1}{e^{2\pi\Omega/a}-1}. \]

  • Энтропия одной бозонной моды: \[ s_U(\Omega) = (1+n_U)\ln(1+n_U)-n_U\ln n_U. \]

  • Это не энтропия полного Минковского вакуума.

  • Полный вакуум остаётся чистым: \[ S(|0_M\rangle\langle0_M|)=0. \]

  • Энтропия появляется после ограничения на правый клин Риндлера: \[ \rho_R= \mathrm{Tr}_L\,|0_M\rangle\langle0_M|. \]

Редуцированное состояние правого клина

  • Для ускоренного наблюдателя доступны только степени свободы правого клина.

  • После трассировки левого клина: \[ \rho_R = \frac{1}{Z} \exp\left( -\frac{2\pi}{a}\hat H_R \right). \]

  • Это тепловая матрица плотности при \[ T_U=\frac{a}{2\pi}. \]

  • Её энтропия: \[ S_R = -\mathrm{Tr}\,\rho_R\ln\rho_R. \]

  • В континуальной КТП эта энтропия расходится: это энтропия запутанности через горизонт Риндлера.

Ускоренная система с ненулевым числом частиц

  • Если состояние имеет риндлеровское occupation number \[ N_R(\Omega) = \langle \hat b_\Omega^\dagger\hat b_\Omega\rangle, \] то \[ S_R(\Omega) = \frac{N_R(\Omega)}{\Omega}. \]

  • Для риндлеровского теплового состояния: \[ N_R(\Omega) = \frac{1}{e^{\beta_R\Omega}-1}. \]

  • Для Минковского вакуума: \[ N_R(\Omega)=n_U(\Omega) = \frac{1}{e^{2\pi\Omega/a}-1}. \]

  • Поэтому эффект Унру можно формулировать как \[ |0_M\rangle \quad\text{выглядит как}\quad \rho_R\sim e^{-2\pi\hat H_R/a}. \]

Итог

  • Инерциальный наблюдатель: \[ \langle0_M| \hat g_{\rm I}^\dagger(\Omega) \hat g_{\rm I}(\Omega') |0_M\rangle=0. \]

  • Ускоренный наблюдатель: \[ \langle0_M| \hat g_{\rm R}^\dagger(\Omega) \hat g_{\rm R}(\Omega') |0_M\rangle = 2\pi\delta(\Omega-\Omega') \frac{1}{\Omega} \frac{1}{e^{2\pi\Omega/a}-1}. \]

  • Значит вакуум Минковского имеет нулевую температуру для инерциального наблюдателя, но выглядит тепловым для ускоренного наблюдателя.

  • Температура: \[ \boxed{ T_U=\frac{\hbar a}{2\pi k_B c}. } \]
